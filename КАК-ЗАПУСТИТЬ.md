# Как запустить Prom Loader на Windows — пошагово для новичка

Prom Loader — программа для подготовки товаров и выгрузки их на Prom.ua. Она работает прямо на вашем компьютере и открывается в браузере как обычный сайт. Ничего не нужно знать про программирование: всё запускается **одним двойным щелчком**.

**Что понадобится:** компьютер с Windows 10 или 11 и интернет (при первом запуске программа докачивает то, что ей нужно).

---

## Шаг 1. Скачайте программу

1. Откройте в браузере ссылку: **https://github.com/egwyl666/test/archive/refs/heads/main.zip**
   (или на странице https://github.com/egwyl666/test нажмите зелёную кнопку **«Code»** → **«Download ZIP»**).
   Если GitHub просит войти — войдите в аккаунт, которому дали доступ к программе.
2. Скачается файл-архив `test-main.zip` (обычно в папку «Загрузки»).

## Шаг 2. Распакуйте архив

1. Откройте папку «Загрузки», найдите `test-main.zip`.
2. Нажмите на него **правой кнопкой мыши** → **«Извлечь всё…»** → **«Извлечь»**.
3. Появится обычная папка `test-main`. Перенесите её в удобное место, например в «Документы».

> ⚠️ **Не запускайте программу прямо из архива** (не заходите внутрь .zip двойным щелчком) — сначала распакуйте. Иначе она не сможет сохранить ваши товары.

## Шаг 3. Запустите

1. Откройте папку `test-main`.
2. **Дважды щёлкните по файлу `START.bat`** (может показываться просто как `START`, с иконкой шестерёнки).
3. При первом запуске откроется чёрное окно — в нём видно, как идёт установка. Это только один раз.

**Если появилось синее окно «Система Windows защитила ваш компьютер»:** нажмите **«Подробнее»** → **«Выполнить в любом случае»**. Windows так реагирует на любые программы, скачанные из интернета.

**Что будет при самом первом запуске:**

- Если на компьютере нет Python (это «двигатель», на котором работает программа), `START.bat` **установит его сам**. Если Windows спросит разрешение — нажмите «Да». После установки окно попросит **закрыть его и запустить `START.bat` ещё раз** — так и сделайте.
- Затем программа 1–3 минуты скачивает свои компоненты. Просто подождите.
- Когда всё готово — чёрное окно закроется, **сам откроется браузер** со страницей «Добро пожаловать», а на рабочем столе появится ярлык **«Prom Loader»**.

**В следующие разы** запускайте программу ярлыком **«Prom Loader» на рабочем столе** — стартует за несколько секунд, без всяких чёрных окон.

### Где программа, когда она работает

Программа работает «в фоне», как Viber или антивирус. Её **значок (фиолетовый квадрат с буквой P) — справа внизу, у часов**.
Если значка не видно — нажмите на маленькую стрелочку **^** рядом с часами, он там.

- **Щелчок по значку** — открыть программу в браузере.
- **Правая кнопка по значку** — меню: «Открыть», «Перезапустить», «Папка с данными», **«Выключить»**.
- Закрыли вкладку браузера — программа продолжает работать; снова откройте её щелчком по значку или ярлыком.

## Шаг 4. Первая настройка (в браузере)

При первом запуске откроется страница **«Настройки»**. Заполните:

1. **Название магазина** — видно в превью карточек.
2. **API-токен Prom** — нужен, чтобы отправлять товары на Prom.
   Где взять: в кабинете компании на Prom в настройках есть раздел управления **API-токенами** (для товаров токену нужны права на товары). Если такого раздела не видите — напишите в поддержку или своему менеджеру Prom: «нужен API-токен для загрузки товаров».
   Вставьте токен и нажмите **«Проверить подключение»**.
   *Без токена тоже можно работать: товары создаются и сохраняются, отправить их на Prom можно позже.*
3. **ИИ-помощник** (по желанию, бесплатно) — помогает писать описания и переводить на украинский:
   1. Откройте https://aistudio.google.com/apikey и войдите своим Google-аккаунтом (Gmail).
   2. Нажмите **«Create API key»** / **«Get API key»** и скопируйте ключ (длинная строка, начинается с `AIza`).
   3. В настройках программы выберите **«Google Gemini»**, вставьте ключ, нажмите **«Проверить»**, затем **«Сохранить»**.

## Как пользоваться — коротко

| Что хочу сделать | Куда нажать |
|---|---|
| Добавить один товар | **«+ Новый товар»** вверху справа. Фото — просто перетащите мышкой в окно. Всё сохраняется само. |
| Красиво оформить описание | В описании есть кнопки: **Ж** (жирный), **Заголовок**, **Список**, **▦ Характеристики** — как в Word. |
| Загрузить много товаров из Excel | **«Импорт файла»** → перетащите Excel → над каждой колонкой выберите, что в ней → «Проверить» → «Импортировать». |
| Подключить прайс поставщика | **«Поставщики»** → «Добавить поставщика» → вставьте ссылку на прайс или перетащите файл → отметьте колонки → «Сохранить и обновить». |
| Перевести на украинский сразу много товаров | **«Товары»** → отметьте галочками → **«✨ ИИ»** → «Перевести на украинский» → «Запустить». Не понравилось — кнопка «Откатить». |
| Посмотреть заказы с Prom | **«Заказы»** — новые заказы появляются сами (проверка каждые 5 минут), там же кнопки «Принят», «Выполнен», «Отменён». |
| Загрузить товары, которые уже есть на Prom | **«Товары»** → кнопка **«⬇ Каталог с Prom»** вверху. |
| Настроить наценку | **«Наценка»** → «Добавить правило», например +30% с округлением «на 9». |
| Посмотреть или поменять курс доллара | **«Наценка»** → блок **«💱 Курс валют»**: по НБУ (сам, раз в день) или свой. Галочка «сразу отправлять новые цены на Prom» — и при смене курса цены на Prom обновятся сами. |
| Загрузил прайс, а цены оптовые | **«Товары»** → отметьте товары → **«💲 Цены»** → «Текущая цена — это опт» → «Применить». Розничная посчитается по наценке. |
| Посмотреть, что поменялось у товаров | **«Журнал»** — что было, что стало, кто поменял. В карточке товара — «🕘 История изменений». |
| Товар на Prom стал «Готов» / «Черновик» по ошибке | Отметьте его → **«Вернуть «На Prom»»**. |
| Удалить товар и с Prom | Отметьте → **«Удалить»** → «Удалить и на Prom». Товар уйдёт из списка, когда Prom подтвердит удаление; если Prom недоступен — программа повторит сама. |
| Проверить, что в программе и на Prom одно и то же | **«⬇ Каталог с Prom»**: товары с Prom, которых нет в программе, загрузятся; товары, которых на Prom больше нет, попадут в «Ошибка». |
| Отправить товары на Prom | **«Товары»** → отметьте галочками → **«Отправить на Prom»**. Ход отправки виден вверху страницы. |

Если отправка на Prom не удалась (нет интернета, Prom недоступен) — **ничего не теряется**: программа повторит сама, а у товара будет видно, что пошло не так.

### Выгрузка по расписанию и отключения света

В «Настройках» → **«Выгрузка на Prom по расписанию»** можно задать время, например «каждый день в 9:00»: программа сама отправит на Prom всё, что «готово к отправке».

- Расписание работает, **пока программа запущена**. Поставьте там же галочку **«Запускать Prom Loader вместе с Windows»** — тогда после включения компьютера программа запустится сама.
- **Если в назначенное время не было света** или компьютер был выключен — при следующем запуске программа поступит так, как вы выбрали:
  - **«спросить меня»** (так по умолчанию): вверху страницы появится вопрос «Выгрузить сейчас / Отложить на час / Пропустить»;
  - **«выгрузить сразу»** — отправит сразу после запуска;
  - **«пропустить»** — дождётся следующего раза.
- Если свет пропал **во время** отправки — ничего не теряется: отправка продолжится после запуска программы.

### Уведомления в Telegram (по желанию)

Можно получать в Telegram сообщения о новых заказах, о выполненной выгрузке и о проблемах (не отправилось на Prom, не обновился поставщик, пропущена выгрузка по расписанию). Настройка — «Настройки» → «Уведомления в Telegram», там пошаговая инструкция на 3 шага.

Уведомления приходят **только тем, кого вы добавили** в список «Получатели», — посторонний, даже найдя вашего бота, ничего не получит. У каждого получателя свои галочки: например, вам — заказы и ошибки, менеджеру — только «выгрузка выполнена». Добавить человека: он открывает бота и жмёт «Старт», вы жмёте «Кто написал боту» → «Добавить». Можно добавить и по ID чата вручную.

### 🆘 Если что-то не работает — кнопка «Не получается?»

Справа внизу на каждой странице есть кнопка **«🆘 Не получается?»** (и раздел «Поддержка» в меню, и пункт «Сообщить о проблеме» в меню значка у часов). Опишите своими словами, что делали, и приложите скриншот: **Win + Shift + S** → выделите область → вернитесь в окно и нажмите **Ctrl+V**. Можно перетащить файлы (картинки, PDF, Excel).

- Обращение **сразу сохраняется на компьютере** — даже если нет интернета, ничего не потеряется.
- Если разработчик настроил приём обращений — оно уйдёт ему в Telegram автоматически (нет связи — программа дошлёт сама).
- Если не настроено — нажмите «Скачать архив» и перешлите файл разработчику в любом мессенджере.
- Вместе с обращением (галочку можно снять) уходит техническая информация: версия программы, число товаров, последние ошибки и журнал работы. **Токены, ключи и пароли не отправляются**; нажмите «посмотреть», чтобы увидеть, что именно уйдёт.

## Про фото и Prom

Prom не принимает фото файлами — он **сам скачивает их по ссылке**. Программа это учитывает:

- **Фото по ссылкам** (от поставщика или добавленные кнопкой «Добавить по ссылке») уходят на Prom как есть.
- **Фото с компьютера и картинки, вставленные в Excel**, нужно где-то выложить, чтобы Prom их забрал. Способ выбирается в «Настройках» → **«Фото для Prom»**:

**Хранилище Cloudflare R2 — рекомендуется.** Каждое фото один раз загружается в ваше хранилище и получает постоянную ссылку. Prom забирает фото когда угодно, даже если компьютер выключен, и не скачивает их заново при каждой выгрузке. Бесплатно до 10 ГБ (примерно 50–100 тысяч фото). Настройка — один раз, около 10 минут:

1. Зарегистрируйтесь на cloudflare.com (бесплатно), слева откройте **R2 Object Storage**. Cloudflare попросит привязать карту: до 10 ГБ хранения и миллиона загрузок в месяц ничего не списывается, а скачивание фото Prom'ом бесплатно всегда.
2. **Create bucket** → имя, например `promloader-photos` → Create.
3. В бакете: **Settings → Public access → R2.dev subdomain → Allow**. Скопируйте адрес **Public R2.dev Bucket URL** (вида `https://pub-….r2.dev`).
4. На главной странице R2 справа скопируйте **Account ID**. Там же **Manage API tokens** → **Create API token**: права **Object Read & Write**, выберите свой бакет → Create.
5. Скопируйте **Access Key ID** и **Secret Access Key** (секрет показывается один раз!).
6. В программе: «Настройки» → «Фото для Prom» → «Хранилище Cloudflare R2» → вставьте пять значений → **«Проверить R2»** → зелёная надпись → **«Сохранить»**.

Дальше всё само: новые фото загружаются в хранилище в фоне, а перед отправкой программа догружает то, что не успела.

**Временный доступ через Cloudflare — без настройки.** На время отправки программа открывает адрес, через который видны **только фото** (не товары и не настройки), и закрывает его через 30 минут. Работает сразу, но компьютер должен быть включён, пока Prom скачивает фото, а адрес каждый раз новый. При первой отправке программа сама скачает помощник Cloudflare (около 40 МБ).

## Где хранятся мои товары и как не потерять их

Всё хранится в папке **`data`** внутри папки программы (`test-main\data`): база товаров и загруженные фото.
Открыть её можно из меню значка у часов → «Папка с данными».

- **Резервные копии делаются сами:** каждый день и перед каждым обновлением (хранятся последние 7).
- В «Настройках» → «Резервные копии» можно **скачать** копию (сохраните её на флешку или в облако — на случай, если сломается сам компьютер) и **восстановить** любую копию одной кнопкой.
- **Не удаляйте папку `data`** — в ней все ваши товары.

## Обновления — программа обновляется сама

- При каждом запуске программа проверяет, вышла ли новая версия, и **сама её устанавливает** (перед этим делает резервную копию).
- Если во время работы вышла новая версия — вверху страницы появится фиолетовая полоса «Доступна новая версия». Нажмите её → **«Обновить сейчас»**. Программа перезапустится примерно за минуту, страница обновится сама.
- Если новая версия вдруг не запустится — программа **сама вернёт предыдущую** и больше эту версию ставить не будет.
- Выключить автоматическую установку можно в «Настройках» → «Обновления программы».

> Пока репозиторий программы на GitHub закрытый, для обновлений нужен «токен» — ключ только для чтения. Как его получить, написано в «Настройках» → «Обновления программы» → «Доступ к обновлениям». Обычно это один раз делает тот, кто дал вам программу.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| Не могу найти программу / значок | Значок — справа внизу у часов, иногда спрятан под стрелочкой **^**. Или просто нажмите ярлык «Prom Loader» — откроется та же программа. |
| Как выключить программу | Правая кнопка по значку у часов → «Выключить». |
| Выскочило окно «Prom Loader остановился из-за ошибки» | Снова запустите ярлык и нажмите «🆘 Не получается?» — журнал приложится сам. Если программа не запускается — отправьте разработчику файл журнала, указанный в окне. |
| Чёрное окно мигнуло и сразу закрылось (при первом запуске) | Скорее всего, программа запущена из архива. Распакуйте (шаг 2) и запустите `START.bat` из распакованной папки. |
| «Python не найден» и не установился сам | Откроется сайт python.org: скачайте Python, при установке **поставьте галочку «Add python.exe to PATH»** внизу первого окна, затем «Install Now». Потом снова `START.bat`. |
| «Не удалось скачать компоненты программы» | Проверьте интернет и запустите `START.bat` ещё раз. Антивирус может мешать скачиванию — временно разрешите. |
| Браузер не открылся сам | Откройте браузер и введите адрес **http://localhost:8000** (точный адрес написан в чёрном окне). |
| Пишет «не нашёл свободный порт» | Перезагрузите компьютер и запустите снова. |
| Страница в браузере «не открывается» | Программа выключена — запустите ярлык «Prom Loader». |
| Что-то непонятное | Нажмите **«🆘 Не получается?»** справа внизу, опишите проблему и вставьте скриншот (**Win + Shift + S**, затем **Ctrl+V**). Если программа совсем не открывается — отправьте разработчику скриншот и файл `data\logs\promloader.log`. |
