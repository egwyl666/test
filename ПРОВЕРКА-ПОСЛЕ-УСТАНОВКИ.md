# Проверка после установки (≈ 40 минут)

Эти проверки нельзя было сделать без настоящего Windows, настоящего кабинета Prom и настоящего Telegram.
Идите по порядку, ставьте галочки. Если что-то не так — сразу жмите **«🆘 Не получается?»** (пункт 5 проверяется первым,
чтобы дальше жаловаться было удобно) или делайте скриншот.

Для проверок заведите **2–3 тестовых товара** с артикулами вида `TEST-1`, `TEST-2`, чтобы потом легко удалить их в кабинете Prom.

## 1. Установка и запуск (Windows)

- [ ] Скачать архив, распаковать, запустить `START.bat` → через 1–3 минуты открылся браузер с программой.
- [ ] Чёрное окно не висит; у часов появился значок Prom Loader (может быть под стрелочкой **^**).
- [ ] На рабочем столе есть ярлык «Prom Loader». Закрыть браузер → двойной клик по ярлыку → открылась та же программа (второй раз не запускается).
- [ ] Правая кнопка по значку → «Перезапустить» → страница сама обновилась через несколько секунд.
- [ ] Правая кнопка по значку → «Выключить» → страница перестала открываться. Снова ярлык — всё на месте.

## 2. Подключение к Prom

- [ ] «Настройки» → вставить API-токен Prom (кабинет Prom → Настройки → Управление API-токенами; права: товары, заказы) → «Проверить подключение» — зелёная галочка.
- [ ] «⬇ Каталог с Prom» — ваши товары из кабинета появились в списке, с фото и ценами.

## 3. Выгрузка товара (самое важное)

- [ ] «Настройки» → «Фото для Prom» → «Хранилище Cloudflare R2» → настроить по инструкции в этом блоке → **«Проверить R2»** — зелёная надпись → «Сохранить».

- [ ] Создать товар `TEST-1`: название, цена, 2 фото **с компьютера** (перетащить), описание с жирным текстом и списком.
- [ ] Превью справа похоже на Prom. Пометить «готов», «Отправить на Prom».
- [ ] В панели отправки статус дошёл до «Готово» (1–5 минут). В кабинете Prom товар есть, **фото на месте**, описание с форматированием.
  - Откройте фото товара в кабинете Prom: правой кнопкой → «Открыть изображение в новой вкладке». Адрес должен начинаться с `images.prom.ua` (Prom скопировал фото к себе).
  - Выключите компьютер на час, затем проверьте товар ещё раз — фото на месте.
  - Если фото не появились — напишите в поддержку, приложите скриншот.
- [ ] Товар из **Excel со вставленными в ячейки картинками** → отправить → фото на Prom на месте.
- [ ] Поменять у `TEST-1` только цену → «Отправить» → в кабинете цена обновилась **за секунды** (быстрое обновление).
- [ ] Поменять название → отправить → обновилось (полная выгрузка).

## 4. Импорт и поставщики

- [ ] «Импорт файла» → ваш настоящий Excel-прайс → указать колонки → создать 3–5 товаров → они в списке, с фото если были.
- [ ] «Поставщики» → добавить реального поставщика по ссылке (или файлом) → «Обновить» → товары создались, цены посчитаны по наценке.
- [ ] В карточке одного товара поставщика поменять цену руками → «Обновить» поставщика ещё раз → ваша цена **не затёрлась** (🔒 своё).

## 4а. Цены, курс и журнал

- [ ] «Наценка» → «💱 Курс валют» — виден курс доллара НБУ. Поставить «свой» 45 → «Сохранить» → у товаров с закупкой в $ цены пересчитались; если они были на Prom и стоит галочка «сразу отправлять» — через минуту цены на Prom новые.
- [ ] Импортировать прайс, где цена — оптовая → отметить товары → «💲 Цены» → «Текущая цена — это опт» → цены стали розничными по наценке.
- [ ] «Журнал» — видны все эти изменения: было → стало, кто поменял. «Скачать для Excel» открывается в Excel с русскими буквами.
- [ ] Товар «На Prom» пометить «Готов» → отметить → «Вернуть «На Prom»» → статус снова «На Prom».

## 4в. Список товаров

- [ ] «Сортировка» → «сначала дорогие» — самый дорогой товар сверху. «Группа» → любая группа — в списке только она; чип «группа: … ×» снимает фильтр.
- [ ] «Ещё фильтры» → «без фото» / «с ошибками заполнения» — видны только такие товары.
- [ ] Отметить 2 товара → «✏ Изменить» → группа «Акция» → «Применить» → у обоих новая группа.
- [ ] «⬇ Excel» — скачался файл, открывается в Excel, в нём те же товары, что на экране.
- [ ] Открыть товар из отфильтрованного списка → «← К списку» — фильтры на месте.

## 4г. Карточка и откат

- [ ] В карточке выгруженного товара — кнопка «Открыть на Prom ↗» → открывается этот товар в кабинете Prom.
- [ ] Поменять цену → «🕘 История изменений» → «↩ Вернуть» у этой строки → цена прежняя, в истории появилась строка «Откат: Цена».
- [ ] «🔍 Проверка выгрузки» в карточке открывает проверку именно этого товара.

## 4д. «Что изменится»

- [ ] У поставщика «👁 Что изменится» → окно с новыми товарами и ценами было → станет → «Отмена» → в списке товаров ничего не поменялось. Снова «👁 Что изменится» → «Обновить» → изменилось ровно то, что было в окне.
- [ ] «Наценка» → поменять свой курс → «Сохранить и пересчитать цены» → окно «изменится N цен» → «Отмена» → курс прежний.
- [ ] Поставщику указать неверную ссылку → «Обновить сейчас» → на всех страницах жёлтая полоска «Поставщик … не обновился», у «Поставщики» — «!»; его товары и прайс не пострадали.

## 4е. После большой проверки (2.0.0)

- [ ] Прайс поставщика в долларах **без правил наценки** (страница «Наценка» → удалить все правила) → «Обновить» →
  у товара цена в гривнах = розничная цена из прайса × курс. Поменять курс → цена изменилась вместе с ним.
- [ ] Товар с закупкой в $ и ценой «🔒 своё» → нажать «🔒 своё» → цена посчиталась по наценке и курсу (не в 40 раз меньше).
- [ ] Если включены фото через туннель: открыть публичный адрес (тот, что начинается на `https://…trycloudflare.com`)
  в браузере — вместо программы сообщение «открывается только по адресу localhost». Фото товаров по нему открываются.
- [ ] Поставщик: поменять «Префикс артикула», не сохраняя, подождать во время обновления 10 секунд — значение
  осталось; «👁 Что изменится» — сначала «Настройки сохранены».
- [ ] Карточка: ввести в цену «абв» → поле красное, внизу «исправьте поле, остальное сохранено»; исправить → «Сохранено ✓».
- [ ] Быстро дважды нажать «Отправить на Prom» в карточке → в панели отправки одно новое задание.

## 4б. Удаление и сверка с Prom

- [ ] Отправить `TEST-3` на Prom → отметить → «Удалить» → «Удалить и на Prom» → статус «Удаляется с Prom», через несколько секунд товар пропал из списка; в кабинете Prom его нет. В «Журнале» — «удалён на Prom».
- [ ] Удалить товар поставщика → «Обновить» поставщика → товар **не** появился снова. На странице поставщика блок «Удалённые вами товары» → отметить его → «Вернуть выбранные» → через несколько секунд товар снова в списке.
- [ ] В поиске набрать название маленькими буквами (например «кроссовки») — находятся товары «Кроссовки…».
- [ ] Удалить тестовый товар в **кабинете Prom** → «⬇ Каталог с Prom» → в программе он в «Ошибка» с причиной «Товара нет на Prom».

## 5. Поддержка и Telegram

- [ ] Кнопка **«🆘 Не получается?»** справа внизу → написать «тест» → **Win+Shift+S**, выделить кусок экрана → вернуться, **Ctrl+V** → скриншот появился → «Отправить».
  - Если бот поддержки не настроен — внизу обращение «сохранено на компьютере», кнопка «Скачать архив» скачивает ZIP.
- [ ] Для себя (разработчика): создать **отдельного** бота у @BotFather для поддержки → «Настройки» → «Куда уходят обращения» → токен → написать боту → «Найти чат» → кликнуть чат → «Сохранить». Отправить обращение ещё раз — пришло в Telegram с фото и файлом диагностики.
- [ ] Бот уведомлений магазина (другой бот): вставить токен → вы и ещё один человек жмёте «Старт» у бота → «Кто написал боту» → добавить обоих.
- [ ] Второму человеку оставить только «выгрузка выполнена». Нажать «Тест» у каждого — сообщения пришли. Отправить `TEST-2` на Prom — второму пришло «выгрузка выполнена», вам — нет (если галочка снята).
- [ ] Третий человек пишет боту, но вы его не добавляете — ему ничего не приходит.

## 6. Заказы

- [ ] «Заказы» — видны реальные заказы из кабинета.
- [ ] Сделать тестовый заказ `TEST-1` с другого аккаунта (или дождаться реального) → в течение 5 минут он на странице «Заказы» и пришёл в Telegram.
- [ ] Сменить статус тестового заказа на «Принят» → в кабинете Prom статус такой же. Отменить с причиной → в кабинете отменён.
- [ ] Если у вас больше 100 заказов: «Все» показывает полное число, «Показать ещё» догружает следующие.
- [ ] Поиск: номер заказа, телефон (можно с пробелами: `050 123 45 67`), фамилия, название товара; даты «с» и «по».
- [ ] Новый заказ остаётся «не просмотрен», пока вы не нажмёте на эту отметку, не позвоните по номеру или не смените статус.
- [ ] Выключить программу → сделать тестовый заказ → через 15 минут включить → заказ появился, уведомление в Telegram пришло.
- [ ] Отключить интернет → дождаться нового заказа (или нажать «↻ Проверить новые» после включения) → в «Настройках» у
  Telegram видно «Не доставлено уведомлений: …»; включить интернет → уведомление пришло само (в течение минуты-двух).
- [ ] Если смена статуса не прошла (например, у токена нет права «Заказы»), программа пишет причину, а статус в
  программе не меняется.

## 7. Расписание и отключение света

- [ ] «Настройки» → «Выгрузка по расписанию» → время через 3 минуты, «спросить меня» → пометить `TEST-2` «готов» → дождаться → он отправился сам.
- [ ] Поставить время через 3 минуты → **выключить** программу (значок → «Выключить») → подождать 15 минут → запустить → сверху вопрос «Выгрузить сейчас / Отложить / Пропустить».
- [ ] Галочка «Запускать вместе с Windows» → перезагрузить компьютер → значок у часов появился сам.

## 8. ИИ (если нужен)

- [ ] «Настройки» → ключ Gemini → «Проверить» → зелёная галочка.
- [ ] Вверху любой страницы значок «✨ авто» (или название модели) → нажать → окно «ИИ»: список моделей с ценой запроса в гривнах.
- [ ] В окне «ИИ» → «Проверить модели» → у моделей появились «✓ работает» / «✗ недоступна» / «⏳ лимит»; под кнопкой — сколько стоила проверка.
- [ ] В карточке «✨ Улучшить описание» → результат по-русски, без выдумок; над ним строка «модель · токены · ≈ … грн» → «Применить».
- [ ] Значок «✨» показывает «сегодня ≈ … грн»; в окне «ИИ» этот запрос есть в «Последних запросах».
- [ ] Выделить 3 товара → «✨ ИИ» → в окне написано, сколько примерно обойдётся → «Перевести на украинский» → «Запустить» → тексты у всех трёх заменились; у задания «потрачено ≈ … грн»; кнопка «Откатить» возвращает прежние.
- [ ] (Если есть ключ Claude) в окне «ИИ» выбрать Claude → после запроса в разделе «Лимиты» видно, сколько запросов и токенов осталось.

## 9. Обновления и копии

- [ ] «Настройки» → «Обновления» → «Проверить обновления» → «У вас последняя версия 2.3.0» (или предложит новую).
- [ ] «Резервные копии» → «Сделать копию сейчас» → копия появилась в списке, её можно скачать.

## 10. Мелочи (2.2.0)

- [ ] В меню на всех страницах одинаковые пункты, есть «Проверка выгрузки»; текущая страница подсвечена.
- [ ] На главной блок «Первые шаги» с галочками (виден, пока не всё сделано); «Скрыть» убирает его.
- [ ] Выключить программу (значок у часов → «Выключить»), не закрывая вкладку, нажать любую кнопку → сверху красная
  полоска «Нет связи с программой». Запустить ярлыком → «Проверить» в полоске → полоска пропала.
- [ ] На телефоне: в карточке товара «Действия ▾» (Дублировать, Удалить…), в списке — «Ещё ▾».
- [ ] Через сутки работы: папка `data/logs` — файлы `promloader.log` (не больше 5 МБ, старые — `.1`, `.2`) и `console.log`.

## После проверки

- Удалите тестовые товары `TEST-…` в кабинете Prom и в программе.
- Всё, что не сработало, — через «🆘 Не получается?»: обращение сохранится, даже если отправка не настроена.
