# Prom Loader

Программа для владельца магазина на Prom.ua: прайсы поставщиков → наценка → карточки товаров → Prom, и дальше —
заказы, Новая Почта, чат с покупателями, остатки и отчёты. Работает на своём компьютере (Windows), открывается в
браузере, с телефона — по Wi‑Fi или через Cloudflare. Интерфейс на русском и украинском, светлая и тёмная тема.

Главная идея: **товар сначала сохраняется у вас, а на Prom уходит отдельным шагом**. Если Prom или интернет «упали»,
ничего не пропадает: товар остаётся в списке со статусом «Ошибка», временные сбои очередь повторяет сама.

> **Не программист и у вас Windows?** Пошаговая инструкция — **[КАК-ЗАПУСТИТЬ.md](КАК-ЗАПУСТИТЬ.md)**: двойной щелчок
> по `START.bat`, всё нужное установится само. Где что лежит — [docs/КАРТА-ПРОГРАММЫ.md](docs/КАРТА-ПРОГРАММЫ.md);
> что проверить руками после установки — [ПРОВЕРКА-ПОСЛЕ-УСТАНОВКИ.md](ПРОВЕРКА-ПОСЛЕ-УСТАНОВКИ.md);
> что нового — [ЧТО-НОВОГО.md](ЧТО-НОВОГО.md); что дальше — [ПЛАН-РАЗВИТИЯ.md](ПЛАН-РАЗВИТИЯ.md).

## Что умеет

| Раздел | Коротко |
|---|---|
| **Сегодня** | итоги заказов и «Требует внимания» — новые заказы, посылки на отделении, чат, ошибки, что заканчивается |
| **Товары** | лента этапов (черновик → готов → на Prom), фильтры, поиск, массовые действия с «↩ Отменить», дубли, конфликты с кабинетом Prom, Excel |
| **Карточка** | фото (перетаскивание, вставка, ссылки), редактор описания, превью «как на Prom» RU/UA, характеристики, видео YouTube, категория Prom, история с «↩ Вернуть», ручные правки «🔒 своё» не затирает поставщик |
| **Поставщики** | XML/YML, Excel, CSV, Google Таблицы по ссылке или файлом; колонки подбираются сами; «👁 Что изменится» до применения; защита от битого прайса; вторая (украинская) ссылка; заказ поставщику по продажам |
| **Наценка и курс** | правила по поставщику, группе и цене, округление «на 9», РРЦ; курс НБУ или свой; сторож наценки |
| **Выгрузка на Prom** | YML через API Prom с очередью и повторами, быстрое обновление цен и наличия, расписание, синхронизация с кабинетом, удаление на Prom, внешние ID, категории, постоянная ссылка фида |
| **Фото для Prom** | Cloudflare R2 (постоянные ссылки) или временный туннель Cloudflare |
| **Заказы** | все заказы Prom с поиском и статусами, ТТН Новой Почты (создание, этикетка, статус посылки), скан штрихкода, упаковка, рисковые покупатели и предоплата, списание остатка по выполненному заказу |
| **Чат** | диалоги Prom, готовые ответы с данными заказа и ТТН, черновик ответа ИИ |
| **Отзывы** | отзывы о магазине с Prom (оценка, товар, заказ, без ответа / негативные), черновик ответа ИИ для кабинета Prom; вопросы «Написать продавцу» с ответом из программы |
| **Отчёты** | продажи, прибыль, ABC, товары без продаж, поставщики, качество каталога; Excel |
| **ИИ** | Gemini или Claude: описания, переводы RU↔UA, ключевые слова, заполнение по фото, группа и категория Prom; массово с оценкой цены и откатом; видно модель, токены и стоимость |
| **Люди и доступ** | вход по логину и паролю, роли (Администратор, Менеджер, Оператор заказов, Только просмотр, свои); телефон по Wi‑Fi или через Cloudflare, значок «как приложение» и push |
| **Уведомления** | Telegram (у каждого получателя свои события, итоги дня) и push на телефон |
| **Обслуживание** | автообновление с откатом, резервные копии (и в R2), переезд на другой компьютер, «🆘 Не получается?» с журналом |

## Запуск

**Windows, одной кнопкой:** `START.bat` найдёт или установит Python (winget), создаст `.venv`, поставит зависимости,
сделает ярлык и запустит программу без консоли: значок у часов (`promloader/tray.py`) присматривает за сервером,
перезапускает его после обновлений и откатывает неудачную версию. Журнал — `data/logs/promloader.log`.

**Вручную (любая ОС)**, нужен Python 3.10+:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
uvicorn promloader.main:app --host 127.0.0.1 --port 8000
```

Откройте http://localhost:8000 — программа попросит создать администратора. Данные (база SQLite, фото, копии) —
в папке `data/`.

**Docker / сервер:** см. `Dockerfile`. Снаружи программа открывается только за паролем `APP_PASSWORD` (базовая
авторизация перед входом пользователя); фото и фид для Prom остаются открытыми — их забирает Prom.

### Переменные окружения (необязательно — всё задаётся и в «Настройках»)

| Переменная | Назначение |
|---|---|
| `PROMLOADER_DATA` | папка с данными (по умолчанию `data`) |
| `PROM_API_TOKEN`, `PROM_API_BASE` | токен Prom и адрес API (по умолчанию `https://my.prom.ua/api/v1`) |
| `PUBLIC_BASE_URL` | постоянный публичный адрес (сервер) — для фото и фида |
| `FEED_KEY` | ключ ссылки фида `/feed/prom.yml?key=…` |
| `APP_PASSWORD` | пароль на вход снаружи (Docker, VPS) |
| `PROMLOADER_ALLOWED_HOSTS` | дополнительные адреса, по которым программа открывается, если запущена не через `START.bat` |
| `AI_PROVIDER`, `GEMINI_API_KEY`, `GEMINI_MODEL`, `ANTHROPIC_API_KEY`, `CLAUDE_MODEL` | ИИ |
| `TELEGRAM_BOT_TOKEN` | бот уведомлений |
| `PROMLOADER_PHOTO_STORAGE`, `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`, `R2_PUBLIC_URL` | фото в Cloudflare R2 |
| `PROMLOADER_SUPPORT_TOKEN`, `PROMLOADER_SUPPORT_CHAT` | отдельный бот, куда уходят обращения «🆘» |
| `PROMLOADER_GITHUB_TOKEN`, `PROMLOADER_UPDATE_REPO` | обновления из закрытого репозитория |

## Обновления

Версия — в `VERSION`, изменения — в `ЧТО-НОВОГО.md` (разделы `## x.y.z`: программа показывает пользователю те, что
новее его версии). Программа сверяет `VERSION` в ветке `main` и ставит новую версию сама — с резервной копией и
откатом. Выпуск: поднять `VERSION`, дописать `ЧТО-НОВОГО.md` (и пункт в `ПРОВЕРКА-ПОСЛЕ-УСТАНОВКИ.md`, если нужна
ручная проверка), влить в `main` — GitHub Actions прогонит ruff и все тесты.

## Для разработчика

- Карты кода: `docs/CODEMAPS/` — [architecture](docs/CODEMAPS/architecture.md), [backend](docs/CODEMAPS/backend.md),
  [frontend](docs/CODEMAPS/frontend.md), [data](docs/CODEMAPS/data.md).
- Сервер — FastAPI (`promloader/main.py` + `promloader/routes/`), база — SQLite (`db.py`, миграции в `MIGRATIONS`),
  интерфейс — HTML + JS без сборки (`promloader/static/`), сторонние файлы — только `static/vendor/`.
- Всё, что пишет пользователь, — под `translate="no"`; новые строки интерфейса — с переводом в `static/i18n-uk.js`
  (тест `test_i18n.py` не пропустит без него).
- Тесты: `pip install -r requirements-dev.txt && python -m pytest`. Prom, НБУ, Новая Почта, ИИ и Telegram в тестах
  подменяются — тесты не ходят в интернет. Браузерные тесты (`test_browser*.py`) нужны Playwright и Chromium, без
  них пропускаются.
- Точные поля API Prom собраны в `promloader/prom_api.py`, теги YML — в `promloader/feed.py`.
