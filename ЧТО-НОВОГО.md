# Что нового

## 1.3.9

- Найдена причина «Prom нашёл 0 товаров» (проверено на живом кабинете): сразу после отправки Prom отвечает «SUCCESS» с нулевыми счётчиками — это значит «файл принят», а товары он создаёт в фоне ещё 1–3 минуты и только потом сообщает «создано/обновлено». Программа принимала первое «SUCCESS» за окончание. Теперь она ждёт, пока Prom отчитается по всем товарам файла; в блоке «Отправка на Prom» видно «Prom принял файл (товаров: N) и обрабатывает их».

## 1.3.8

- «🔍 Проверка выгрузки» (кнопка в блоке «Отправка на Prom»): один товар проходит весь путь до Prom по шагам — токен, есть ли товар на Prom, файл, фото, отправка, обработка у Prom, появился ли товар (программа спрашивает Prom по артикулу). Видно, на каком шаге проблема и что ответил Prom; отчёт можно скопировать или отправить в поддержку. Если работает только импорт по ссылке, программа запомнит это для обычных выгрузок.

## 1.3.7

- Prom запускает импорты по одному. Если он ответил «действует ограничение на запуск одновременных импортов», программа теперь ждёт и повторяет сама (каждые 2 минуты, до 12 часов), а не ставит товарам «Ошибка». Выгрузки, упавшие так в прошлых версиях, при запуске встают в очередь заново.
- Исправлено: любой отказ Prom (HTTP 400) выключал передачу списка «что обновлять». Теперь — только если Prom пожаловался именно на этот список.

## 1.3.6

- Если Prom «не видит» товаров в загруженном через API файле (тот же файл, загруженный вручную, импортируется), программа сама повторяет выгрузку по ссылке — как «Завантажити файл з сервера» в кабинете — и дальше отправляет этим способом. Файл выкладывается туда же, где фото: в хранилище R2 или через временный доступ (только файл выгрузки со случайным именем).
- Файл загружается на Prom с тем же типом, что и из браузера.

## 1.3.5

- У каждой выгрузки записывается, что именно ушло на Prom: версия программы, размер файла, число товаров и настройки импорта — для разбора проблем.

## 1.3.4

- Выгрузка на Prom передаёт список «что обновлять» (название, описание, цена, фото, наличие, группа, характеристики…) — как галочки «Інформація, яку потрібно оновити» в ручном импорте. Если Prom такой список не примет, программа сама отправит файл без него.

## 1.3.3

- Исправлено: если Prom отвечал «успешно», но не находил в файле ни одного товара (total: 0), программа ошибочно помечала товары «На Prom». Теперь такая выгрузка считается неудачной, а товары, «выгруженные» так раньше, при запуске возвращаются в «ошибку» — их можно отправить кнопкой «Повторить».
- В файле выгрузки теперь всегда есть обязательные для YML название, компания и адрес магазина, а у каждого товара — категория (товары без группы попадают в «Без группы»).
- У каждой выгрузки кнопка «Скачать файл»: этот файл можно загрузить в кабинете Prom вручную и увидеть подробный отчёт Prom.

## 1.3.2

- Выгрузки на Prom идут по одной: пока Prom обрабатывает предыдущий импорт, следующий ждёт (в программе видно «Ждёт, пока Prom закончит выгрузку №…»). Всё, что накопилось за это время — ручная отправка, обновление поставщика, расписание, — уходит одним файлом, а не отдельными импортами.

## 1.3.1

- ИИ Gemini: модель выбирается автоматически из тех, что доступны вашему ключу (Google регулярно отключает старые модели). Если модель убрали — программа сама переключится на другую; поле «Модель» можно оставить пустым.
- «Модель перегружена» (ошибка 503 у Google): программа сама повторяет запрос и пробует другую модель; массовый ИИ в таком случае ждёт и продолжает, а не помечает товары ошибкой. Сообщения об этом — по-русски.

## 1.3.0

- Фото с компьютера и из Excel можно хранить в Cloudflare R2 (бесплатно до 10 ГБ): у каждого фото постоянная ссылка, Prom забирает фото, даже когда компьютер выключен, и не скачивает их заново при каждой выгрузке. Настройка — «Настройки» → «Фото для Prom», там пошаговая инструкция и кнопка «Проверить R2».
- Новые фото загружаются в хранилище заранее, в фоне, — отправка на Prom не ждёт.

## 1.2.0

- «Поддержка»: кнопка «🆘 Не получается?» на каждой странице — описание, скриншот (Ctrl+V или перетащить), техническая информация без паролей. Обращение сразу сохраняется на компьютере, уходит разработчику в Telegram (отдельный бот поддержки), без интернета — дошлётся позже; можно скачать архивом.
- Telegram: несколько получателей, каждому — свой набор уведомлений; новое событие «выгрузка на Prom выполнена». Посторонние, нашедшие бота, ничего не получают.
- Найдены и исправлены ошибки «нетипичного» использования: странные числа (1e10, «12,5 грн»), невидимые символы из Excel ломали фид, ссылка без https://, ошибки при неверных данных в правилах наценки и расписании, файл не того типа молча игнорировался, одно неверное поле мешало сохранить остальные.
- Меню не вылезает за экран на телефоне и в узком окне.

## 1.1.0

- Автообновление программы: проверка новой версии, установка одной кнопкой или автоматически при запуске, откат, если новая версия не запустилась.
- Резервные копии: каждый день автоматически и перед каждым обновлением; скачать или восстановить можно в «Настройках».
- Фото с компьютера теперь попадают на Prom: на время отправки программа открывает временный доступ только к фото (Cloudflare).
- Выгрузка на Prom по расписанию; если в это время компьютер был выключен — программа спросит «Выгрузить сейчас / Отложить / Пропустить» (или поступит по настройке).
- Галочка «Запускать вместе с Windows».
- Кнопка «Каталог с Prom»: загрузить в программу товары, которые уже есть в кабинете.
- Быстрое обновление цен и наличия: если у товара на Prom поменялись только цена/наличие, он обновляется за секунды без полного импорта.
- Массовый ИИ: выделить товары → «✨ ИИ» → перевод, описания, ключевые слова для всех сразу; с учётом лимитов, паузой и откатом.
- Несколько поставщиков на один товар (по штрихкоду): описание — от основного, цена и наличие — от самого дешёвого, у кого товар есть.
- Заказы с Prom: страница «Заказы», проверка каждые 5 минут, смена статуса (принят / выполнен / отменён).
- Уведомления в Telegram (по желанию): новые заказы, ошибки отправки, сбои поставщиков, пропущенная выгрузка.
- Программа работает без чёрного окна: значок у часов с меню «Открыть / Перезапустить / Папка с данными / Выключить».
