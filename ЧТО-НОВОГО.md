# Что нового

## 2.17.0

- **Выручка на странице «Заказы».** Над списком — четыре карточки: сегодня, вчера, 7 дней и этот месяц. В каждой
  выручка, число заказов и прибыль. Отменённые заказы не считаются.
- **Вкладка «Статистика товаров» на странице «Заказы».** По каждому товару за выбранный период:
  - сколько заказов и штук;
  - выручка и доля от общей;
  - прибыль (закупка на дату заказа; «≈» — если закупка взята текущая);
  - сколько раз отменяли.

  Можно сортировать нажатием на заголовок, искать по названию или артикулу и скачать в Excel. Ссылка
  `/orders#stats` сразу открывает эту вкладку.
- **Сводка за день в Telegram — в 21:00.** Число заказов, выручка (и сравнение со вчера), средний чек, прибыль,
  отмены и три товара с наибольшей выручкой. Новое событие «сводка за день» включено всем получателям. Если не
  нужно — снимите галочку в «Настройки» → «Уведомления в Telegram». Если в 21:00 компьютер выключен, сводка за
  этот день не придёт: утром её не досылаем.

## 2.16.8

- **Обновление прайса больше не превращает цену продажи в закупочную.** Если для товара не было правила наценки,
  новая закупка из прайса записывалась и в цену. Так случалось и у товаров, которые уже продаются на Prom с
  нормальной ценой: следующая отправка выставила бы их по закупке.
  - Теперь без правила наценки цена товара остаётся прежней, меняется только закупка.
  - Цена по закупке ставится только новому товару, у которого цены ещё нет.
  - Если поставщик даёт РРЦ, цена, как и раньше, = РРЦ по курсу.
  - Чтобы цены сами следовали за закупкой — задайте правило на странице «Наценка».
- **Новая закупка или РРЦ не отправляют товар на Prom заново.** Prom их не видит, а товар зря попадал в «Готов к
  отправке».

## 2.16.7

- **Выгрузка на Prom не дублируется, пока Prom держит файл в очереди.** Prom сначала отвечает «принято, товаров: 0»
  и разбирает файл, когда до него дойдёт очередь: иногда через минуты, иногда через часы. Через 15 минут программа
  считала, что Prom «не увидел товаров», и отправляла тот же файл ещё раз по ссылке — второй импорт вставал в ту же
  очередь.
  - Теперь программа ждёт до часа.
  - Пока ждёт, пишет: «Файл ждёт в очереди импорта Prom уже N мин».

## 2.16.6

- **Над списком товаров больше не висят устаревшие сообщения.**
  - «N товаров считались выгруженными, но на Prom их нет» — теперь число считается по товарам, которые есть в
    программе сейчас. Раньше программа запоминала число из прошлой загрузки каталога и показывала его даже после
    того, как эти товары удалили. Рядом — ссылка «показать их».
  - «ID на Prom записаны не все: нет связи…» — у старой ошибки появилась кнопка «Скрыть».

## 2.16.5

- **Уведомления в Telegram больше не приходят пачкой с опозданием.** Сообщения каждому получателю уходят по
  очереди. Если Telegram отклонял одно сообщение (например, из-за символа «<» в имени или адресе), программа
  повторяла его до двух суток, а все следующие уведомления ждали за ним.
  - Такое сообщение теперь уходит простым текстом, а если и так не принято — помечается «не доставлено», и очередь
    идёт дальше.
  - Если Telegram просит подождать, программа ждёт ровно столько, сколько он сказал.
- **Новый адрес для телефона приходит и тем, кто подключил Telegram раньше.** Новые события — «новый адрес для
  входа с телефона», «посылку долго не забирают», «отказ от посылки» — включены всем получателям один раз.
  Выключить можно в «Настройках» → Telegram.

## 2.16.4

- **Доступ через Cloudflare больше не «пересоздаётся по кругу».** Программа проверяла новый адрес запросом через
  интернет со своего же компьютера, а новый адрес появляется в интернете с задержкой — Windows запоминала «такого
  адреса нет», и программа считала адрес нерабочим, закрывала его и делала следующий. Теперь готовность определяется
  по сообщению самого cloudflared о соединении с Cloudflare. Адрес пересоздаётся, только если Cloudflare сам отвечает
  ошибкой туннеля (1033).
- В списке адресов для Wi‑Fi домашние адреса `192.168.…` идут первыми; адреса VPN, Hyper-V и WSL (`172.16…`) — ниже.

## 2.16.2

- **Ссылка для телефона от прошлого запуска больше не даёт непонятную ошибку.** Если программу закрыли окном, старый
  cloudflared на Windows оставался жить и по старой ссылке открывал отказ — на iPhone ещё и кракозябрами.
  - Теперь любая ссылка через Cloudflare ведёт на вход по паролю.
  - Оставшийся от прошлого запуска cloudflared программа закрывает сама при старте.
  - Отказ, если доступ из интернета выключен, — понятная страница по-русски, а не набор символов.

## 2.16.1

- **Адрес для телефона через Cloudflare больше не «умирает» молча.** После сна компьютера или смены сети туннель
  терял связь с Cloudflare, и по ссылке открывалась «Ошибка 1033». Программа при этом считала адрес рабочим и
  новый не создавала.
  - Теперь адрес проверяется каждые 3 минуты.
  - Если он дважды подряд не открывается, программа сама создаёт новый и присылает свежую ссылку в Telegram.

## 2.16.0 — Новая Почта

- **Отслеживание посылок — сразу, без настройки.**
  - Программа сама следит за всеми посылками магазина, в том числе с ТТН, созданными в кабинете Prom.
  - У заказа видны номер ТТН и статус: «В пути», «На отделении», «Получена», «Отказ / возврат».
  - Уведомления в Telegram и на телефон:
    - «посылку долго не забирают» — по умолчанию через 5 дней на отделении: успеете напомнить покупателю до
      платного хранения;
    - «отказ или возврат»;
    - по желанию — «посылка прибыла в отделение».
- **ТТН в один клик.** «Заказы» → «📦 Создать ТТН»: форма уже заполнена из заказа Prom — получатель, телефон, город,
  отделение, сумма.
  - Для неоплаченного заказа (наложенный платёж) сумма к получению включена сама. Снять её без предупреждения
    нельзя — посылку не отдадут бесплатно.
  - Номер ТТН сам передаётся в заказ на Prom.
  - «🖨 Этикетка 100×100» — PDF для печати; «Удалить ТТН» — пока посылка не отправлена.
- **Настройка** — «Настройки» → «🚚 Новая Почта»:
  - ключ API → «Проверить ключ» — программа сама найдёт вас как отправителя;
  - контактное лицо, телефон, город и отделение отправки;
  - вес, описание и плательщик по умолчанию, через сколько дней напоминать.

## 2.15.0 — приложение на телефоне

- **Значок Prom Loader на главном экране телефона.** Открывается как обычное приложение — без адресной строки, со
  своим значком. «Настройки» → «📲 Приложение на телефоне»:
  - **Android (Chrome):** кнопка «📲 Установить на телефон» или меню ⋮ → «Установить приложение»;
  - **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
- **Уведомления прямо на телефон — без Telegram.**
  - О новых заказах, сообщениях покупателей, ошибках отправки и сбоях поставщиков. События выбираются галочками,
    есть кнопка «Проверить уведомление».
  - Текст уведомления зашифрован — его видит только ваш телефон.
  - Работают по защищённому адресу Cloudflare (https). На iPhone — только у значка на экране «Домой», iOS 16.4 и
    новее.
- **Компьютер выключен** — вместо ошибки браузера понятная страница «Нет связи с программой» с кнопкой
  «Повторить».
- **Обновления не залипают.** Приложение ничего не хранит у себя: после обновления программы телефон сразу
  получает новую версию.
- **Адрес Cloudflare меняется при каждом запуске программы.** Значок, добавленный по такому адресу, работает до
  перезапуска. Потом откройте новый адрес из Telegram или QR-кода и добавьте значок заново. Адрес по Wi‑Fi дома
  не меняется, но уведомлений по нему нет: браузеры разрешают их только на https.
- Для уведомлений программа сама доустановит компонент `cryptography`. Если его нет, уведомлений не будет, всё
  остальное работает.

## 2.14.0 — переезд на другой компьютер или сервер

- **«Настройки» → «📦 Переезд на другой компьютер или сервер».** Переносится всё:
  - товары, заказы, чаты, настройки;
  - прайсы поставщиков и фото;
  - **все ключи и токены** — Prom, ИИ, Telegram, R2, пароль входа с телефона и ключ фида. Ссылка автоимпорта в
    кабинете Prom продолжает работать.
- **На старом компьютере:**
  - придумайте пароль копии и нажмите «Создать пакет переезда»;
  - ключи в файле зашифрованы этим паролем, без него файл бесполезен;
  - если все фото уже в R2, снимите «фото с компьютера» — файл получится в мегабайты, а не в гигабайты;
  - можно сразу отправить пакет в облако R2;
  - можно поставить этот компьютер на паузу.
- **Пауза старого компьютера.**
  - Он перестаёт забирать заказы и чат, отправлять товары и слать уведомления — без двойных заказов в Telegram.
  - Вверху всех страниц видна полоска «⏸ Программа на паузе» с кнопкой «Включить обратно».
- **На новом компьютере или сервере.** На свежей установке в «Первых шагах» есть кнопка «📦 Перенести данные…».
  - Выберите файл — программа покажет, что в нём: товары, поставщики, заказы, чаты, фото.
  - Введите пароль → «Восстановить». Неверный пароль ничего не меняет.
- **«Код подключения к облаку».**
  - Короткий код вида `PLK1-…`, зашифрованный тем же паролем.
  - На новом компьютере: код + пароль → программа сама подключается к R2 и показывает облачные копии.
- **«Запомнить пароль для облачных копий».** Ежедневные копии в облаке тоже везут ключи — зашифрованными. Без
  пароля, как и раньше, ключей в облаке нет совсем.
- Имена файлов фото и прайсов в базе приводятся к виду, который работает и на Windows, и на Linux (Docker).
- Автопроверка на GitHub больше не запускается дважды на один и тот же код.

## 2.13.0 — технический фундамент

- **Копии и в облаке R2.** «Настройки» → «Резервные копии» → «Хранить копии и в облаке R2». Пункт виден, если
  подключено хранилище R2 для фото.
  - Ежедневные и ручные копии уходят ещё и в облако; там хранятся последние 10.
  - Токены, ключи и пароль в облачную копию **не попадают**.
  - Имя файла в облаке случайное — его не угадать.
  - Восстановить можно прямо из списка, токены этого компьютера при этом сохраняются. На новом компьютере их
    нужно будет ввести заново.
- **Защита пароля `APP_PASSWORD`** (сервер в сети, Docker): после 5 неверных паролей с одного адреса за 5 минут вход
  с этого адреса закрывается на 5 минут, а в Telegram приходит тревога.
  - Вход с телефона и раньше закрывался после 10 неверных паролей за 15 минут, теперь при этом тоже приходит
    тревога в Telegram.
- **Под капотом:**
  - сервер разделён на разделы — один файл в 2000 строк стал 16 небольших, новые функции проще добавлять без
    ошибок;
  - база SQLite стала устойчивее к сбоям и не падает с «database is locked»;
  - раз в сутки база сама обновляет свою статистику, чтобы запросы оставались быстрыми;
  - файл выгрузки задания собирается одним запросом, а не запросом на каждый товар;
  - разобранный при импорте прайс сразу выгружается из памяти;
  - фид для автоимпорта никогда не открывается с пустым ключом.
- **Автопроверка на GitHub:** при каждом обновлении кода сами запускаются все тесты (более 500) и проверка кода.
  Сломанная версия не дойдёт до автообновления незамеченной.

## 2.12.0

## 2.10.0

- **Доступ с телефона.** «Настройки» → «📱 Доступ с телефона». Программа по-прежнему работает на компьютере, а
  телефон открывает её в браузере. Компьютер и программа должны быть включены.
  - **Пароль.** Сначала придумайте пароль (не меньше 8 символов). Телефон спрашивает его один раз и помнит
    30 дней. На самом компьютере пароль не нужен, как и раньше.
  - **Дома — по Wi‑Fi.** Телефон и компьютер подключены к одному роутеру. После включения программа
    перезапустится. В настройках появятся адрес вида `http://192.168.…:8000/` и QR-код: наведите на него камеру
    телефона.
    - Windows при первом включении спросит, разрешить ли Python доступ к сети: отметьте «Частные сети» и нажмите
      «Разрешить».
  - **Из любого места — через Cloudflare.** Бесплатный защищённый адрес `https://….trycloudflare.com` с QR-кодом.
    - Адрес меняется при каждом запуске программы. Новый адрес приходит в Telegram: событие «новый адрес для
      входа с телефона». Новым получателям оно включено сразу; тем, кто уже есть, его надо включить в списке
      событий получателя.
  - На телефоне в меню есть «Выйти».
  - «Выйти на всех телефонах» и смена пароля закрывают все прежние входы.
  - **Безопасность:**
    - пароль и сам доступ меняются только на компьютере;
    - после 10 неверных паролей подряд вход закрывается на 15 минут;
    - выключить программу с телефона нельзя;
    - «свой» компьютер программа узнаёт по настоящему адресу подключения, а не по заголовку, который можно
      подделать.

## 2.9.0

- **Чат с покупателями.** Новый раздел меню «Чат» — переписка с покупателями Prom прямо в программе.
  - Слева диалоги (поиск, «Непрочитанные»), справа переписка: карточка товара, о котором спрашивают, ссылка на
    заказ покупателя, фото, которые он прислал.
  - Ответ — из программы. Шаблоны в одно нажатие: «Товар в наличии…», «Отправим сегодня Новой Почтой», «Сейчас

  - «✨ Черновик ИИ» — ИИ предлагает ответ по переписке и данным товара (цена, наличие, характеристики). Ответ
    попадает в поле — вы проверяете и отправляете сами. Видно, сколько стоил запрос.
  - Новые сообщения программа проверяет каждую минуту. В меню — число непрочитанных, в Telegram — уведомление о
    новом сообщении покупателя: включите «новые сообщения покупателей в чате Prom» у получателя в «Настройках».
    Новым получателям оно включено сразу.
  - Открыли диалог — сообщения отмечаются прочитанными и на Prom.
- Чтение чата проверено на живом магазине. Отправку ответа проверить на живом магазине не удалось: писать
  настоящим покупателям ради проверки нельзя. Первый ответ из программы лучше отправить себе — напишите магазину
  со своего аккаунта покупателя и ответьте из «Чата».

## 2.8.0

- **Отчёты.** Новый раздел меню «Отчёты»: период (сегодня, 7 и 30 дней, этот месяц, свой) и четыре вкладки.
  У каждой — «⬇ Excel».
  - **Продажи:** заказы, выручка, средний чек, прибыль, комиссия Prom, график по дням, отмены и их причины.
    Отменённые заказы в выручку и прибыль не входят.
  - **Прибыль** = сумма продажи − закупка − комиссия Prom (её Prom берёт почти с каждого заказа, около 13–17%).
    Закупка берётся такой, какой она была на день заказа (по журналу изменений). Если закупка ни разу не менялась —
    берётся текущая, рядом знак «≈». Закупка в $ и € — по курсу программы сейчас. Видно, для какой доли выручки
    закупка известна.

## 1.6.2

Этап 1 плана развития — безопасность и надёжность.

- **Защита от чужих сайтов.** Раньше любой сайт, открытый в том же браузере, мог незаметно отправить программе команду: восстановить подложенную резервную копию, запустить обновление, перезапуск или пересчёт цен, а через подмену адреса — даже прочитать копию с токенами. Теперь программа отвечает только по своему адресу (`localhost`) и выполняет изменяющие команды только со своих страниц.
- **Резервные копии.** При восстановлении принимаются только база, фото и прайсы — архив с посторонними файлами отклоняется; база в копии проверяется на целостность. Откуда брать обновления — настройка этого компьютера: восстановленная копия её не меняет. Большая копия загружается частями, а не целиком в память.
- **Не подвисает.** Если сайт НБУ недоступен, программа не ждёт его снова 10 минут (раньше каждый товар в валюте мог открываться до 20 секунд). Курс берётся до записи в базу, а не во время неё. Список товаров, карточка, загрузка фото и сборка файла для Prom больше не задерживают остальную программу.
- **Товары не застревают в «Отправляется».** Итог выгрузки и статусы товаров записываются одним действием; если программу выключили в неудачный момент, при запуске такие товары возвращаются в «Готов к отправке» с пояснением.
- **Изменения поставщика не теряются.** Если обновление прайса оборвалось на середине, уже изменённые цены всё равно уходят на Prom (раньше при следующем обновлении они выглядели «без изменений» и оставались старыми).
- **Быстрое обновление цены ждёт импорт.** Если товар ещё в импорте, который Prom обрабатывает, новая цена уходит после него — иначе импорт мог вернуть старую цену.
- Слишком большая картинка (больше 90 мегапикселей) — понятное сообщение вместо ошибки.

- Исправлено: любой отказ Prom (HTTP 400) выключал передачу списка «что обновлять». Теперь — только если Prom пожаловался именно на этот список.

## 1.3.6

- Если Prom «не видит» товаров в загруженном через API файле (тот же файл, загруженный вручную, импортируется), программа сама повторяет выгрузку по ссылке — как «Завантажити файл з сервера» в кабинете — и дальше отправляет этим способом. Файл выкладывается туда же, где фото: в хранилище R2 или через временный доступ (только файл выгрузки со случайным именем).
- Файл загружается на Prom с тем же типом, что и из браузера.

## 1.3.5

- У каждой выгрузки записывается, что именно ушло на Prom: версия программы, размер файла, число товаров и настройки импорта — для разбора проблем.

## 1.3.4

- Выгрузка на Prom передаёт список «что обновлять» (название, описание, цена, фото, наличие, группа, характеристики…) — как галочки «Інформація, яку потрібно оновити» в ручном импорте. Если Prom такой список не примет, программа сама отправит файл без него.

## 1.3.3

- Исправлено: если Prom отвечал «успешно», но не находил в файле ни одного товара (total: 0), программа ошибочно помечала товары «На Prom». Теперь такая выгрузка считается неудачной, а товары, «выгруженные» так раньше, при запуске возвращаются в «ошибку» — их можно отправить кнопкой «Повторить».
- В файле выгрузки теперь всегда есть обязательные для YML название, компания и адрес магазина, а у каждого товара — категория (товары без группы попадают в «Без группы»).
- У каждой выгрузки кнопка «Скачать файл»: этот файл можно загрузить в кабинете Prom вручную и увидеть подробный отчёт Prom.

## 1.3.2

- Выгрузки на Prom идут по одной: пока Prom обрабатывает предыдущий импорт, следующий ждёт (в программе видно «Ждёт, пока Prom закончит выгрузку №…»). Всё, что накопилось за это время — ручная отправка, обновление поставщика, расписание, — уходит одним файлом, а не отдельными импортами.

## 1.3.1

- ИИ Gemini: модель выбирается автоматически из тех, что доступны вашему ключу (Google регулярно отключает старые модели). Если модель убрали — программа сама переключится на другую; поле «Модель» можно оставить пустым.
- «Модель перегружена» (ошибка 503 у Google): программа сама повторяет запрос и пробует другую модель; массовый ИИ в таком случае ждёт и продолжает, а не помечает товары ошибкой. Сообщения об этом — по-русски.
