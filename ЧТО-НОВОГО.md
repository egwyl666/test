# Что нового

## 1.1.0

- Автообновление программы: проверка новой версии, установка одной кнопкой или автоматически при запуске, откат, если новая версия не запустилась.
- Резервные копии: каждый день автоматически и перед каждым обновлением; скачать или восстановить можно в «Настройках».
- Программа работает без чёрного окна: значок у часов с меню «Открыть / Перезапустить / Папка с данными / Выключить».

## 1.0.0

- Первая версия: товары, импорт из Excel, поставщики, наценка, ИИ-помощник, визуальный редактор описания, запуск одной кнопкой.
