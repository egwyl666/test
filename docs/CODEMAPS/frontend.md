# Страницы и JS (`promloader/static/`)

_Обновлено: 2026-10-05 · версия 1.7.0_

Чистый JS без сборки. Каждая страница подключает `common.js` (`api()`, `$`/`$$`, `esc`, `toast`, `formatPrice`,
`formatDate`, `statusBadge`, `loadMeta` → `META` (+ полоски: обновление, нет токена Prom, пропущенная выгрузка), `initNav`, кнопка «🆘 Не получается?»). Стили — `app.css`
(мобильная вёрстка до 640 px: `.hide-sm`/`.show-sm`). Меню повторяется в каждом HTML.

| Адрес | Файлы | Что там |
|---|---|---|
| `/` | `index.html`, `list.js` | Список товаров: статусы, поиск, поставщик, фильтры (`FILTERS` — группа, наличие, «Ещё фильтры»), сортировка, «⬇ Excel»; вид списка в адресе (`syncUrl`, `sessionStorage promloader-list-url` для «← К списку»); «Ничего не найдено»; «✏ Изменить» (`openEditModal`); отметки + «выбрать все N по фильтру» (`selection()` → `{ids}` или `{filter}`); колонки «Закупка» и «Цена» (наценка, 🔒 вручную, «было …»); массовые действия: отправить, статусы, «Вернуть «На Prom»», ✨ ИИ, 💲 Цены (опт → закупка с выбором валюты), удалить (окно «и на Prom / только из программы», в строке «Повторить» / «Отменить удаление»); очередь отправки; «⬇ Каталог с Prom» и итог сверки |
| `/product?id=` | `product.html`, `product.js`, `preview.js`, `richtext.js` | Карточка: автосохранение и резерв в браузере, фото (перетаскивание, порядок), закупка и валюта, 🔒 закреплённые поля, поставщики товара, ИИ-помощник, проверка перед отправкой, превью как на Prom, «🕘 История изменений» |
| `/import` | `import.html`, `import.js`, `mapping.js` | Импорт Excel/CSV/XML: лист, строки, назначение колонок (по 200 строк, «Показать ещё»), проверка карточек |
| `/suppliers`, `/supplier?id=` | `suppliers.html`, `supplier.html`, `supplier.js`, `suppliers-common.js`, `mapping.js` | Поставщики: источник, колонки, расписание, свой курс, очистка названий, история обновлений (`runSummary`), блок «Удалённые вами товары» (вернуть выбранные/все + сразу обновить) |
| `/pricing` | `pricing.html` | «💱 Курс валют» (НБУ / свой, надбавка, автоотправка, на какие товары действует курс), правила наценки, калькулятор |
| `/changes` | `changes.html` | Журнал изменений: период, кто, поле, поиск, CSV; на телефоне — карточки |
| `/orders` | `orders.html` | Заказы Prom и смена статуса |
| `/settings` | `settings.html` | Токен Prom, фото (R2 / туннель / адрес), ИИ, Telegram, расписание, обновления, копии, автозапуск |
| `/support` | `support.html` | Обращения в поддержку со скриншотами |
| `/diagnose` | `diagnose.html` | Пошаговая проверка выгрузки одного товара |

Страницы регистрируются в `main.PAGES`; новая страница = HTML в `static/` + строка в `PAGES` + ссылка в меню всех HTML.
