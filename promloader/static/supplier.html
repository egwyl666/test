1. Откуда брать прайс

Если ссылки нет — перетащите файл прайса в окно или выберите файл. Файл станет текущим прайсом поставщика; при обновлении без ссылки будет использоваться он.

2. Что лежит в колонках

Обязательно отметьте Артикул / код — по нему товар узнаётся при следующих обновлениях. Для закупочной цены выберите «Цена закупки» — розничная посчитается по правилам наценки.

3. Как обновлять

Проверка

Удалённые вами товары:

Эти позиции есть в прайсе, но вы удалили их товары — при обновлении поставщик их не создаёт заново. Вернёте — программа сразу обновит прайс, и товары появятся снова (новыми товарами). Если вы сами создали товар с тем же артикулом, поставщик привяжет его к себе автоматически.
