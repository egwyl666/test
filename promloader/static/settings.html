👋 Добро пожаловать в Prom Loader!

Программа работает у вас на компьютере. Её значок — справа внизу, у часов (если не видно — нажмите на стрелочку ^ рядом с часами). Щелчок по значку — открыть программу, правая кнопка — меню с пунктом «Выключить». В следующий раз запускайте её ярлыком «Prom Loader» на рабочем столе.

С чего начать:

  1. Ниже впишите название магазина — оно видно в превью карточек.
  2. Если уже есть API-токен Prom — вставьте его ниже и нажмите «Проверить подключение». Нет токена — можно пока без него: товары создаются и сохраняются, отправить на Prom сможете позже.
  3. По желанию подключите ИИ-помощника (бесплатно через Google Gemini) — раздел ниже.
  4. Дальше: создайте первый товар, загрузите Excel или добавьте поставщика.

Подробная инструкция — файл «КАК-ЗАПУСТИТЬ.md» в папке программы.

Подключение к Prom.ua

Токен выдаёт Prom (кабинет компании → Настройки → Управление API-токенами, или через менеджера). Нужны права на товары. Токен хранится только на этом сервере.

Заполняйте, только если программа стоит на сервере с постоянным адресом. Для фото с домашнего компьютера — блок «Фото для Prom» ниже.

🖼 Фото для Prom

Prom не принимает фото файлами — он сам скачивает их по ссылкам. Фото из интернета (от поставщика, ссылки в Excel) уже имеют ссылку. А фото с компьютера и картинки, вставленные в Excel, нужно где-то выложить, чтобы Prom смог их забрать. Выберите как:

Как настроить R2 — 10 минут, один раз
  1. Зарегистрируйтесь на cloudflare.com (бесплатно) и откройте слева R2 Object Storage. Cloudflare попросит привязать карту — до 10 ГБ хранения и миллиона загрузок в месяц деньги не списываются, скачивание фото Prom'ом бесплатно всегда.
  2. Create bucket → имя, например promloader-photos → Create. Впишите это имя в поле «Имя бакета».
  3. В бакете: Settings → Public access → R2.dev subdomain → Allow (введите allow для подтверждения). Скопируйте появившийся адрес Public R2.dev Bucket URL (вида https://pub-….r2.dev) в поле «Публичный адрес».
  4. Вернитесь на главную R2 → справа Account details: скопируйте Account ID. Там же Manage API tokens (или «Manage R2 API Tokens») → Create Account API token (подойдёт и User API token): права Object Read & Write, в «Specify bucket» выберите свой бакет → Create.
  5. Cloudflare покажет Access Key ID и Secret Access Key — скопируйте оба сразу, секрет показывается один раз.
  6. Нажмите «Сохранить» и «Проверить». Зелёная надпись — готово: выберите «Хранилище Cloudflare R2» выше.

⏰ Выгрузка на Prom по расписанию

В назначенное время программа сама отправляет на Prom все товары со статусом «готов к отправке». Работает, пока программа запущена. Если в это время компьютер был выключен (например, не было света) — при следующем запуске программа поступит так, как выбрано ниже.

📨 Уведомления в Telegram (по желанию)

  1. В Telegram откройте @BotFather, отправьте ему /newbot, придумайте имя боту. BotFather пришлёт токен — длинную строку вида 123456:ABC-…. Вставьте её ниже и нажмите «Сохранить».
  2. Каждый, кто должен получать уведомления (вы, менеджер, группа), открывает бота и нажимает «Старт».
  3. Нажмите «Кто написал боту» и добавьте нужных людей. Остальные ничего получать не будут — даже если найдут бота. У каждого получателя — свои галочки: кому заказы, кому отчёты о выгрузке.

✨ ИИ-помощник

Помогает в карточке товара: улучшить описание, перевести на украинский, придумать название и ключевые слова. ИИ только предлагает текст — в карточку он попадает после нажатия «Применить».

Ключ бесплатно создаётся в Google AI Studio → «Get API key». На бесплатном тарифе есть лимит запросов в минуту и в день, и Google может использовать запросы для улучшения своих моделей.

Ключ создаётся в консоли Anthropic; оплата по использованию.

🔄 Обновления программы

Установлена версия

Доступ к обновлениям (если репозиторий закрытый)

Программа скачивает обновления с GitHub. Пока репозиторий закрытый, нужен токен только для чтения: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access: Only select repositories (выбрать репозиторий программы) → Permissions: Contents: Read-only → Generate. Скопируйте токен сюда.

💾 Резервные копии

Копия базы товаров и всех фото делается автоматически раз в сутки (хранятся последние 7) и перед каждым обновлением. Для надёжности иногда скачивайте копию на флешку или в облако.

Автоимпорт по ссылке

Эту ссылку можно указать в кабинете Prom в разделе импорта «по ссылке» с автообновлением. Тогда Prom сам будет регулярно забирать все товары, кроме черновиков — даже если кнопку «Отправить» никто не нажмёт.

🆘 Куда уходят обращения в «Поддержку» (для разработчика / того, кто обслуживает программу)

Отдельный бот, не связанный с уведомлениями магазина: обращения из раздела «Поддержка» (описание, скриншоты, техническая информация) приходят в указанный здесь чат. Если не настроено — обращения просто сохраняются на компьютере, их можно скачать архивом и переслать вручную. Разработчик может заранее положить файл support.json в папку программы — тогда здесь ничего заполнять не нужно.
